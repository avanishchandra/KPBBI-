

KPBBI – Intro to Bug Bounty Hunting and Web Application Hacking

About Me

I am a Computer Science postgraduate with a strong interest in cybersecurity, web application security, and ethical hacking.

I created this repository as part of my learning journey to develop a practical understanding of how web applications work, how security vulnerabilities arise, and how they can be identified and responsibly reported.

I am particularly interested in hands-on exploration, understanding the tools and techniques used by security researchers, and developing a research-oriented approach to identifying vulnerabilities.

My Goal: To build a strong foundation in Web Application Security and gradually develop the skills required to become a competent Bug Bounty Hunter and Security Researcher.

Learn. Explore. Break Responsibly. Secure.
